A program that writes exactly one line to `/output/entry.txt`, for the
[make.fun competition](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

## The line

> **Diplomatic Immunity.**
>
> "The crumb presented diplomatic credentials, so I left it alone. I am not starting an international incident over 0.4 grams of biscuit."

A robot vacuum's excuse for missing a spot: the crumb had diplomatic
credentials, and no machine starts an international incident over
0.4 grams of biscuit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is a plain static writer: no network, no secrets, no dynamic
code, no reads outside the repository.
